# Scientific Calculator

A modern scientific calculator built with Python, PySide6, and Qt Designer.

## Planned Features

- Basic arithmetic
- Scientific functions
- Fractions
- Powers and roots
- Summations
- Limits
- Trigonometric functions
- Logarithmic functions
- DEG/RAD/GRAD modes
- Calculation history
- Keyboard input
- Modern GUI
- Windows executable

## Technologies

- Python
- PySide6
- Qt Designer
